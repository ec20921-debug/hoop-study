# 🏀 HOOP STUDY

部活をがんばる中学生のための「毎日1本、勉強のシュート」アプリ。iPhone のホーム画面に追加して使います。

- **本人用** `index.html` — 毎日ミッション／ミニゲーム（英単語スペル・複数形・漢字の読み・一問一答・苦手つぶし）／試合前（テストまでの作戦・目標スコア・準備チェック）／💬声（要望・わからない・苦手を音声入力で送れる）／ガチャ
- **保護者用** `parent.html` — 娘さんの声・今日の様子・連続日数・カレンダー・教科バランス・正答率・苦手リスト・目標・エール送信
- **記録の保存先** — Google スプレッドシート（Apps Script。コードは非公開リポジトリで管理）
- **通知** — 毎週日曜20時に週報メール。「声」が届いたらすぐメール（設定タブで ON/OFF）
- **問題の変更** — スプレッドシートの「問題」タブを編集（「お休み」で出さない、「重点」で3倍出やすい）

## 最初の設定

1. 新しい Google スプレッドシートを作る
2. 「拡張機能 → Apps Script」を開き、Apps Script のコード（非公開リポジトリの `apps/hoop-study/gas/Code.gs`）を貼り付けて保存
3. 関数「setup」を選んで「実行」（許可を求められたら自分のアカウントで許可）
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された URL（`…/exec`）を `config.js` の `GAS_URL` に入れる
   - 動作確認：関数「sendTestReport」を実行すると週報のテストメールが届く
6. スプレッドシートの「設定」タブにある **保護者キー** を、`parent.html` で1回だけ入力する

## iPhone のホーム画面に追加

Safari でアプリの URL を開く → 共有ボタン → 「ホーム画面に追加」。

## 問題を増やす

`data.js` の `SPELL_WORDS` / `PLURAL_WORDS` / `KANJI_WORDS` に1行ずつ足すだけ。
