# 🏀 HOOP STUDY

部活をがんばる中学生のための「毎日1本、勉強のシュート」アプリ。iPhone のホーム画面に追加して使います。

- **本人用** `index.html` — 毎日ミッション／ミニゲーム（英単語スペル・複数形・漢字の読み・一問一答・苦手つぶし・動詞の形・リスニング・スピーキング）／漢字かき取り（読みと例文を見て紙に書く → 自己採点 → 漢字ミッション）／試合前（テストまでの作戦・目標スコア・準備チェック）／💬声（要望・わからない・苦手を音声入力で送れる）／ガチャ
- **保護者用** `parent.html` — 娘さんの声・今日の様子・連続日数・カレンダー・教科バランス・正答率・苦手リスト・目標・エール送信
- **記録の保存先** — Google スプレッドシート（Apps Script。コードは非公開リポジトリで管理）
- **通知** — 毎週日曜20時に週報メール。「声」が届いたらすぐメール（設定タブで ON/OFF）
- **問題の変更** — スプレッドシートの「問題」タブを編集（「お休み」で出さない、「重点」で3倍出やすい）

## 🏆 英検カップ（英検4級プログラム・2026-11-05 に5級で開始 → 11-06 受けるのは4級とわかり全面改訂）

本番は 2027-01-17（`eiken.js` の `EIKEN.date`）。毎日のメニュー（単語→大問→リスニング・約7分）を、おまかせの一番目に出す。

- **問題** `eiken.js`：単語・熟語 605語・大問1〜4（大問1 150問・大問2 45問・大問3 45問・大問4 26文章84問）・リスニング第1〜3部（60・50・50問）。すべてこのアプリ用に作ったオリジナル（公式の過去問は転載しない。公式ページへのリンクだけ）
- **形式** 公式の過去問（2026年度第2回）で確認：リーディング35問・35分（大問4＝掲示2・Eメール3・お話5）／リスニング30問・約30分／大問3は①〜⑤を並べて「2番目と4番目」の組み合わせを答える（`EIKEN.r3Keys`）／リスニングは2回放送・第1部は A→B→A の会話のあと返事3つも放送だけ・第2部と第3部は選択肢4つが画面
- **級を変える時** `EIKEN.grade` を変えると、`migrate` が形式ごとの正答率・模試・過去問・実力チェックを新しくする（単語のおぼえ直しは残す）
- **絵** 第1部だけ。`icons/ek/<説明文のハッシュ>.jpg`（Higgsfield で生成）。説明文を変えるとファイル名が変わるので、絵も作り直す（5級の第3部で使っていた絵も残っている）
- **模試** 各リストの最後の分（`EK_MOCK_ONLY`）は本番模試の専用で、ふだんのメニューには出さない
- **ポイント** 他のゲームと同じ 1問 1P（XP・その日の点には他のゲームと同じように入る）。英検だけのチケットやごほうびの計算は足していない。おこづかいの計算式も変更なし。目標8割はアプリの目安で、公式の合格点ではない
- **合格のごほうび** はま寿司（`EIKEN.reward`・家族の決定）
- 記録は `S.ek`（`sr`＝おぼえ直しの箱と次の日／`rc`＝形式ごとの直近の正誤／`mocks`／`past`）。保護者画面と `hoop_analyze.py` に出る

## 最初の設定

1. 新しい Google スプレッドシートを作る
2. 「拡張機能 → Apps Script」を開き、Apps Script のコード（非公開リポジトリの `apps/hoop-study/gas/Code.gs`）を貼り付けて保存
3. 関数「setup」を選んで「実行」（許可を求められたら自分のアカウントで許可）
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された URL（`…/exec`）を `config.js` の `GAS_URL` に入れる
   - 動作確認：関数「sendTestReport」を実行すると週報のテストメールが届く
6. スプレッドシートの「設定」タブにある **保護者キー** を、`parent.html` で1回だけ入力する

## iPhone のホーム画面に追加

Safari でアプリの URL を開く → 共有ボタン → 「ホーム画面に追加」。

## 問題を増やす

`data.js` の `SPELL_WORDS` / `PLURAL_WORDS` / `KANJI_WORDS` / `KANJI_WRITE`（漢字かき取り）に1行ずつ足すだけ。
